# Notion API 명세서 가이드

이 파일은 `backend/APIs/` 폴더에 생성된 마크다운 파일들을 Notion으로 옮길 때, 각 페이지의 **소개(Introduction)** 및 **요약(Summary)** 으로 사용할 수 있는 텍스트들을 모아둔 것입니다.

## 1. API 전체 소개 (Introduction)
*Notion API 명세서 메인 페이지의 최상단에 붙여넣으세요.*

### 👋 SSAFY Home 부동산 거래 정보 서비스 API v1.0

이 문서는 SSAFY Home 프로젝트의 백엔드 API 명세서입니다.
클라이언트(Frontend)와 서버(Backend) 간의 데이터 통신을 위한 규격을 정의합니다.

#### 기본 정보
- **Base URL**: `http://localhost:8080`
- **Context Path**: `/api/v1` (일부 인증 API는 `/user` 사용)
- **Data Format**: `JSON`

#### 인증 (Authentication)
- **JWT (Json Web Token)** 방식을 사용합니다.
- 로그인 성공 시 `accessToken`과 `refreshToken`이 발급됩니다.
- 인증이 필요한 요청 헤더에는 `Authorization: Bearer <accessToken>`을 포함해야 합니다.

#### 공통 응답 규격
모든 API 응답은 다음과 같은 공통 형식을 따릅니다 (성공 시):

```json
{
  "code": "success",
  "message": "요청이 성공적으로 처리되었습니다.",
  "data": { ... } // 실제 데이터 Payload
}
```

## 2. 모듈별 요약 (Summaries)
*각 API 기능별 Notion 페이지를 만들 때, 최상단에 붙여넣어 해당 모듈의 역할을 설명하세요.*

### 👤 User API (회원 관리)
**파일명**: `User_API_회원_관리.md`

사용자 인증 및 계정 관리를 담당하는 API 모듈입니다.
- **주요 기능**:
    - **회원가입 및 로그인** (JWT 토큰 발급)
    - **회원 정보 조회 및 수정**
    - **비밀번호 재설정** (이메일 발송) 및 변경
    - **이메일 인증**

### ❤️ Favorites API (관심 매물)
**파일명**: `Favorites_API_관심_매물.md`

사용자가 관심 있게 지켜보는 아파트 매물을 관리하는 API 모듈입니다.
- **주요 기능**:
    - **관심 아파트 등록** 및 삭제
    - 내 **관심 목록 조회** (마이페이지 등 활용)
    - 특정 아파트의 **관심 등록 여부 확인** (상세 페이지 활용)

### 🏢 Apartment API (아파트 정보)
**파일명**: `Apartment_API_아파트_정보.md`

개별 아파트의 상세 정보를 제공하는 API 모듈입니다.
- **주요 기능**:
    - **아파트 상세 정보 조회**: 기본 정보, 거래 내역, 평형 정보 등을 제공합니다.

### 🗺️ Area API (지역 검색)
**파일명**: `Area_API_지역_검색.md`

지도 화면 기반으로 영역 내의 아파트 및 지역 정보를 검색하는 API 모듈입니다.
- **주요 기능**:
    - **지도 범위 검색**: 현재 보고 있는 지도 화면(좌표 범위) 내의 아파트 리스트를 조회합니다.
    - **필터링**: 가격, 평형 등 조건에 맞는 매물을 필터링하여 검색합니다.

### 🏷️ Region Code API (지역 코드)
**파일명**: `Region_Code_API_지역_코드.md`

행정구역(시도, 구군, 동) 정보를 조회하는 유틸리티 API 모듈입니다.
- **주요 기능**:
    - **행정구역 목록 조회**: 시도 > 구군 > 동 순서로 선택할 수 있는 데이터를 제공합니다.
    - **법정동 상세 조회**: 법정동 코드로 지역 상세 정보를 조회합니다.

### 🏥 Health Check API (헬스 체크)
**파일명**: `Health_Check_API_헬스_체크.md`

서버의 정상 가동 상태를 확인하는 시스템 API입니다.
- **주요 기능**:
    - **서버 상태 점검**: 서버가 정상적으로 요청을 받을 수 있는 상태인지 확인합니다. (Status: UP)

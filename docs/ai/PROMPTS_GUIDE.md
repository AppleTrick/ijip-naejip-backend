# AI 프롬프트 가이드

본 프로젝트의 AI 챗봇 시스템에서 사용하는 7가지 핵심 프롬프트에 대한 설명입니다.

---

## 📋 프롬프트 목록

### 1️⃣ AI 챗봇 시스템 프롬프트
**파일**: `01_AI_CHATBOT_SYSTEM_PROMPT.txt`  
**의도**: AI가 부동산 데이터 분석가로서 사용자 질문을 이해하고, 스스로 SQL을 생성해 데이터를 조회한 뒤 마크다운 보고서를 작성하도록 지시합니다.

**핵심 전략**:
- **2쿼리 병렬 실행**: 통계 분석 쿼리 + 샘플 아파트 쿼리를 동시에 실행
- **Tool Calling 방식**: AI가 DatabaseQueryTool 함수를 호출해 직접 DB 조회
- **마크다운 보고서**: 이모지, 표, 불렛포인트를 활용한 가독성 높은 분석 결과 제공

---

### 2️⃣ 전역 시스템 프롬프트 (톤앤매너)
**파일**: `02_GLOBAL_SYSTEM_PROMPT.txt`  
**의도**: 모든 AI 응답의 스타일과 태도를 통일합니다. AI의 방어적 태도를 차단하고 자신감 있고 친절한 답변을 유도합니다.

**5가지 핵심 규칙**:
1. **해요체 사용**: 딱딱하지 않고 친근하게
2. **사족 금지**: "정확한 정보는 확인하세요" 같은 책임 회피 멘트 차단
3. **구체성**: "교통이 좋다" → "잠실역이 코앞이다"
4. **가독성**: 이모지와 불렛포인트로 시각화
5. **자신감**: 데이터 기반 정보는 확신 있게 전달

---

### 3️⃣ 필터 파싱 프롬프트
**파일**: `03_FILTER_PARSING_PROMPT.txt`  
**의도**: 자연어로 입력된 조건("30평대 5억 이하")을 JSON 형식으로 빠르게 변환합니다.

**출력 형식**:
- 1줄: 한국어 확인 멘트 (예: "네, 30평대 5억 이하 매물을 찾아보겠습니다.")
- 2줄: JSON 객체 (priceRange, areaRange)

**특징**: 설명이나 질문 없이 즉시 파싱 결과만 반환

---

### 4️⃣ 지역 분석 프롬프트
**파일**: `04_REGIONAL_ANALYSIS_PROMPT.txt`  
**의도**: 특정 지역에 대해 "20년 산 토박이 주민" 관점에서 생생하고 구체적인 정보를 제공합니다.

**분석 항목**:
- 🚇 **교통**: 가까운 지하철역, 주요 도로망
- 🏫 **학군**: 초/중/고 통학 환경, 학원가
- 🌳 **인프라**: 마트, 공원, 병원 등

**특징**: 추상적 표현 금지, 구체적인 랜드마크와 시설명 언급

---

### 5️⃣ 비교 분석 프롬프트
**파일**: `05_COMPARISON_SUMMARY_PROMPT.txt`  
**의도**: 여러 아파트를 비교할 때 "쇼핑 호스트" 처럼 명쾌하게 장단점을 설명하고 5가지 지표로 점수화합니다.

**출력 형식** (JSON):
- `summary`: 마크다운 형식의 비교 분석 리포트
- `scores`: 각 아파트의 5가지 지표 점수 (1~10점)
  - 교통, 학군, 편리성, 환경, 미래가치

**특징**: 데이터가 부족해도 합리적 추론으로 점수 산정

---

### 6️⃣ 입지 매력도 프롬프트
**파일**: `06_LOCATION_ATTRACTIVENESS_PROMPT.txt`  
**의도**: 특정 아파트의 입지적 강점을 **딱 3줄**로 요약합니다.

**출력 형식**:
```
✨ [키워드]: 짧은 설명
✨ [키워드]: 짧은 설명
✨ [키워드]: 짧은 설명
```

**특징**: 요점만 콕 찍어 전달, 가독성 최우선

---

### 7️⃣ 지역 컨텍스트 프롬프트
**파일**: `07_REGION_CONTEXT_PROMPT.txt`  
**의도**: 사용자가 언급한 지역명을 DB에서 검증한 후, AI가 SQL 쿼리 작성 시 정확한 지역명을 사용하도록 가이드합니다.

**핵심 기능**:
- DB 검증된 지역 정보 제공 (sido_name, gugun_name, dong_name)
- dong_code 기반 조인 방법 안내
- SQL WHERE 절 작성 시 오류 방지

**특징**: AI 챗봇 프롬프트에 동적으로 추가되는 컨텍스트

---

## 🎯 프롬프트별 페르소나 요약

| 프롬프트 | 페르소나 | 목적 |
|---------|---------|------|
| 1️⃣ AI 챗봇 | 전문 데이터 분석가 | 복합 데이터 조회 및 보고서 생성 |
| 2️⃣ 전역 | 친절한 부동산 전문가 | 모든 AI 응답의 톤앤매너 통일 |
| 3️⃣ 필터 파싱 | 정확한 데이터 추출기 | 자연어 → JSON 변환 |
| 4️⃣ 지역 분석 | 20년 토박이 주민 | 지역 정보 생생하게 전달 |
| 5️⃣ 비교 분석 | 쇼핑 호스트 | 여러 매물 비교 및 점수화 |
| 6️⃣ 입지 매력도 | 입지 전문가 | 3줄 핵심 요약 |
| 7️⃣ 지역 컨텍스트 | DB 가이드 | SQL 작성 정확도 향상 |
